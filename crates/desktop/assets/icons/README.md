# Application icons

SVGs supplied by the user from `/Users/tangqh/Downloads/icons`.
Colors use `currentColor`; XML declarations and fixed dimensions are removed
for native and inline rendering. The handle is rotated 90 degrees; the resize
triangle is rotated -45 degrees to point toward the bottom-right corner.

`src/icons.rs` bundles the assets and expands `__ICON_name__` placeholders.
Website favicons, selected emoji, and native macOS controls are separate.
